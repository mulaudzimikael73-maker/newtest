MOOD MATCH FIX — files to upload to YourUltimateFanV3-main
============================================================

WHAT WAS WRONG
--------------
In mikael-connection.js, the "Today's Connection" mood-match check
(isMutual) only compared against a small hardcoded keyword list
("miss", "love", "thinking of you", "soft", "happy"). Moods like
"tired", "dramatic", "annoyed", "sad", "indifferent", "emotional" and
"bored" never matched even when you both picked/typed the same word,
and there was no link between Lizzy's "Feeling Like Catwoman" mood
and you typing "Batman".

Separately, v3-main's live mood list (in living-desktop.js) was
missing 4 options that exist in the newer build: "Missing My
Standard", "Feeling Like Catwoman", "Excited", and "Funky".

WHAT THESE 2 FILES FIX
-----------------------
1. living-desktop.js
   Adds the 4 missing mood buttons to Lizzy's "Mood of the Day"
   picker so the full mood list is:
   Happy, Tired, Dramatic, Soft, Annoyed, Missing Mikael, Sad,
   Indifferent, Emotional, Bored, Missing My Standard,
   Feeling Like Catwoman, Excited, Funky.

2. mikael-connection.js
   Rewrites isMutual() so:
   - "Missing Mikael" AND "Missing My Standard" both count as a
     match whenever your typed/telegrammed mood text mentions
     "missing".
   - "Feeling Like Catwoman" counts as a match whenever your mood
     text mentions "Batman" (or "Catwoman").
   - every other mood (Happy, Tired, Dramatic, Soft, Annoyed, Sad,
     Indifferent, Emotional, Bored, Excited, Funky) now matches
     whenever your mood text contains that same word — this covers
     the "any of the other moods that are the same must be a match"
     case that wasn't working before.

HOW TO UPLOAD
--------------
Just upload these two files into the root of your YourUltimateFanV3-main
repo, overwriting the existing living-desktop.js and mikael-connection.js.
No other files need to change — the mood buttons are generated by
JavaScript from the list in living-desktop.js, so index.html does not
need any edits.

Nothing else in your live v3 site is touched. (Note: the "newtest"
build you sent also contains other unrelated new features — a co-op
game, a Mikael HQ letters/chess panel, etc. — none of that is included
here since you only asked for the mood-match fix.)
